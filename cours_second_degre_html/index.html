Équations du type $x^2 = a$ ($a \in \mathbb{R}$)

Soit $x$ une inconnue réelle et $a$ un nombre réel fixé. On cherche à résoudre dans $\mathbb{R}$ l'équation $x^2 = a$.

Cas 1 : $a < 0$

Un carré réel étant toujours positif ou nul ($\forall x \in \mathbb{R}, x^2 \ge 0$), l'équation n'a aucune solution réelle.

$S = \emptyset$

Cas 2 : $a = 0$

L'équation s'écrit $x^2 = 0$. La seule solution est $x = 0$.

$S = \{0\}$

Cas 3 : $a > 0$

L'équation équivaut à $x^2 - a = 0 \iff (x-\sqrt{a})(x+\sqrt{a}) = 0$. Elle admet deux solutions distinctes.

$S = \{-\sqrt{a}\,;\, \sqrt{a}\}$

Trinôme du Second Degré & Forme Canonique

Définition (Trinôme du second degré)

On appelle trinôme du second degré toute fonction polynôme $P$ définie sur $\mathbb{R}$ par : $$P(x) = ax^2 + bx + c$$ où $a, b, c$ sont des réels fixés avec $a \neq 0$.

Démonstration rigoureuse de la Forme Canonique

Puisque $a \neq 0$, nous pouvons factoriser par $a$ :

$$P(x) = a \left[ x^2 + \frac{b}{a}x + \frac{c}{a} \right]$$ $$\text{Remarquons que } x^2 + \frac{b}{a}x \text{ est le début du développement de } \left(x + \frac{b}{2a}\right)^2 = x^2 + \frac{b}{a}x + \frac{b^2}{4a^2}$$ $$\text{D'où : } x^2 + \frac{b}{a}x = \left(x + \frac{b}{2a}\right)^2 - \frac{b^2}{4a^2}$$ $$\text{En substituant : } P(x) = a \left[ \left(x + \frac{b}{2a}\right)^2 - \frac{b^2}{4a^2} + \frac{c}{a} \right] = a \left[ \left(x + \frac{b}{2a}\right)^2 - \frac{b^2 - 4ac}{4a^2} \right]$$

On pose le discriminant : $\mathbf{\Delta = b^2 - 4ac}$.
La forme canonique s'écrit alors : $$P(x) = a \left[ \left(x + \frac{b}{2a}\right)^2 - \frac{\Delta}{4a^2} \right]$$

3

Résolution de l'équation $ax^2 + bx + c = 0$ ($a \neq 0$)

En utilisant la forme canonique, l'équation $P(x) = 0$ équivaut à :

$$\left(x + \frac{b}{2a}\right)^2 = \frac{\Delta}{4a^2}$$

Le dénominateur $4a^2 = (2a)^2$ étant strictement positif, le nombre de solutions dépend uniquement du signe du discriminant $\Delta$.

Signe de $\Delta$ Nombre de solutions Expression des Solutions dans $\mathbb{R}$ Ensemble Solution $S$
$\Delta < 0$ Aucune solution réelle Un carré égal à un nombre négatif est impossible $S = \emptyset$
$\Delta = 0$ Une solution double $x_0 = -\frac{b}{2a}$ $S = \left\{ -\frac{b}{2a} \right\}$
$\Delta > 0$ Deux solutions distinctes $x_1 = \frac{-b - \sqrt{\Delta}}{2a} \quad \text{et} \quad x_2 = \frac{-b + \sqrt{\Delta}}{2a}$ $S = \left\{ \frac{-b - \sqrt{\Delta}}{2a} \,;\, \frac{-b + \sqrt{\Delta}}{2a} \right\}$

Équations Bicarrées

Définition

Une équation bicarrée est une équation de la forme : $$a x^4 + b x^2 + c = 0 \quad (a \neq 0)$$

Méthode de résolution par changement de variable :

  1. On pose $X = x^2$. Puisqu'un carré réel est toujours positif ou nul, la condition impérative est $X \ge 0$.
  2. L'équation devient l'équation du second degré associée : $$aX^2 + bX + c = 0$$
  3. On calcule le discriminant $\Delta_X = b^2 - 4ac$ et on détermine les solutions $X$.
  4. Rejection / Validation :
    • Si une valeur $X < 0$, elle ne donne aucune solution en $x$.
    • Si $X = 0$, alors $x^2 = 0 \implies x = 0$.
    • Si $X > 0$, alors $x^2 = X \implies x = \sqrt{X}$ ou $x = -\sqrt{X}$.
5

Factorisation d'un Trinôme du Second Degré

Soit le trinôme $P(x) = ax^2 + bx + c$ ($a \neq 0$). Sa factorisation dépend directement du signe du discriminant $\Delta$ :

Si $\Delta < 0$

Le trinôme $P(x)$ n'est pas factorisable dans $\mathbb{R}$ sous forme d'un produit de facteurs du premier degré.

Si $\Delta = 0$

Le trinôme s'écrit sous forme d'un carré parfait :

$P(x) = a\left(x - x_0\right)^2$

Si $\Delta > 0$

En désignant par $x_1$ et $x_2$ les deux racines :

$P(x) = a(x - x_1)(x - x_2)$

Signe du Trinôme & Inéquations du 2nd Degré

Règle d'or du Signe du Trinôme

Le trinôme $P(x) = ax^2 + bx + c$ est du signe de $a$ partout, sauf entre ses racines (lorsqu'elles existent, c'est-à-dire quand $\Delta > 0$).

Cas 1 : $\Delta < 0$ (Pas de racine)

$x$ $-\infty$ $+\infty$
$ax^2+bx+c$ Signe de $a$

Cas 2 : $\Delta = 0$ (Racine double $x_0 = -\frac{b}{2a}$)

$x$ $-\infty$ $x_0$ $+\infty$
$ax^2+bx+c$ Signe de $a$ 0 Signe de $a$

Cas 3 : $\Delta > 0$ (Deux racines $x_1 < x_2$)

$x$ $-\infty$ $x_1$ $x_2$ $+\infty$
$ax^2+bx+c$ Signe de $a$ 0 Signe de ($-a$) 0 Signe de $a$

Pièges Cachés & Astuces d'Examen

Les détails qui font gagner des points et évitent les erreurs classiques

Piège #1 : Le coefficient $a$ nul ou paramétrique

Si une équation s'écrit $(m-1)x^2 + 2x + 3 = 0$, attention ! Ce n'est un trinôme du second degré que si $m-1 \neq 0 \iff m \neq 1$. Si $m=1$, l'équation devient $2x+3=0$ (premier degré). N'appliquez jamais $\Delta$ sans vérifier que le coefficient de $x^2$ n'est pas nul !

Piège #2 : Fausses solutions dans les Bicarrées

Lors de la résolution de $ax^4+bx^2+c=0$, si vous trouvez $X_1 = -4$ et $X_2 = 9$, n'écrivez JAMAIS $S = \{-4, 9\}$. L'équation $x^2 = -4$ n'a pas de solution ! Les seules solutions réelles sont $x = \pm\sqrt{9} = \pm 3$, soit $S = \{-3, 3\}$.

Astuce Examen : Racines Évidentes

Avant de foncer tête baissée dans le calcul de $\Delta$, vérifiez ces deux règles d'or :
• Si $a + b + c = 0$, alors $x_1 = 1$ et $x_2 = \frac{c}{a}$.
• Si $a - b + c = 0$, alors $x_1 = -1$ et $x_2 = -\frac{c}{a}$.

Astuce Examen : Discriminant Réduit $\Delta'$

Lorsque le coefficient $b$ est pair ($b = 2b'$), vous pouvez utiliser le discriminant réduit : $$\Delta' = b'^2 - ac$$ Si $\Delta' > 0$, les racines sont exprimées plus simplement par $x = \frac{-b' \pm \sqrt{\Delta'}}{a}$ (sans diviser par $2a$).

Piège #5 : Fractions Rationnelles et Valeurs Interdites

Pour résoudre une inéquation du type $\frac{ax^2+bx+c}{px+q} \le 0$, il faut impérativement poser d'abord le Domaine de Définition ($D_E$) en excluant les racines du dénominateur ($px+q \neq 0$). Dans le tableau de signe final, marquez le pôle par une double barre ($\|$) !

6 Exercices
Exercice 1 : Équations de forme $x^2 = a$ Facile

Résoudre dans $\mathbb{R}$ les équations suivantes :
a) $x^2 = -5$      b) $x^2 = 7$      c) $3x^2 - 12 = 0$

a) $x^2 = -5$ : Le membre de droite est strictement négatif ($-5 < 0$). Un carré réel ne pouvant être négatif, $S_a = \emptyset$.

b) $x^2 = 7$ : $7 > 0$, l'équation possède deux solutions réelles distinctes : $S_b = \{-\sqrt{7}\,;\, \sqrt{7}\}$.

c) $3x^2 - 12 = 0$ : $3x^2 = 12 \iff x^2 = \frac{12}{3} = 4$. Comme $4 > 0$, $x = -\sqrt{4} = -2$ ou $x = \sqrt{4} = 2$. Donc $S_c = \{-2\,;\, 2\}$.

Exercice 2 : Équations du 2nd degré & Racines Évidentes Moyen

Résoudre dans $\mathbb{R}$ :
a) $2x^2 - 5x + 3 = 0$
b) $x^2 + 4x + 5 = 0$
c) $5x^2 + 8x + 3 = 0$

a) $2x^2 - 5x + 3 = 0$ :
Astuce racine évidente : $a+b+c = 2 + (-5) + 3 = 0$.
Donc $x_1 = 1$ et $x_2 = \frac{c}{a} = \frac{3}{2}$.
Vérification par $\Delta$ : $\Delta = (-5)^2 - 4(2)(3) = 25 - 24 = 1 > 0$. Roots: $\frac{5 \pm 1}{4} \implies \{1\,;\, \frac{3}{2}\}$. $S_a = \left\{1\,;\, \frac{3}{2}\right\}$.

b) $x^2 + 4x + 5 = 0$ :
$\Delta = 4^2 - 4(1)(5) = 16 - 20 = -4$.
Comme $\Delta < 0$, l'équation n'a pas de solution réelle. $S_b = \emptyset$.

c) $5x^2 + 8x + 3 = 0$ :
Astuce racine évidente : $a - b + c = 5 - 8 + 3 = 0$.
Donc $x_1 = -1$ et $x_2 = -\frac{c}{a} = -\frac{3}{5}$. $S_c = \left\{-1\,;\, -\frac{3}{5}\right\}$.

Exercice 3 : Équations Bicarrées avec Pièges Difficile / Piège

Résoudre dans $\mathbb{R}$ :
a) $x^4 - 5x^2 + 4 = 0$
b) $x^4 + 3x^2 - 4 = 0$
c) $2x^4 + 5x^2 + 3 = 0$

a) $x^4 - 5x^2 + 4 = 0$ :
Posons $X = x^2$ ($X \ge 0$). L'équation devient $X^2 - 5X + 4 = 0$.
Somme des coefficients $1 - 5 + 4 = 0 \implies X_1 = 1$ et $X_2 = 4$.
Les deux valeurs sont positives ($1 > 0$ et $4 > 0$).
• $x^2 = 1 \implies x = -1$ ou $x = 1$.
• $x^2 = 4 \implies x = -2$ ou $x = 2$.
D'où $S_a = \{-2\,;\, -1\,;\, 1\,;\, 2\}$.

b) $x^4 + 3x^2 - 4 = 0$ :
Posons $X = x^2$ ($X \ge 0$). L'équation devient $X^2 + 3X - 4 = 0$.
$1 + 3 - 4 = 0 \implies X_1 = 1$ et $X_2 = -4$.
Piège ! $X_2 = -4 < 0$, donc l'équation $x^2 = -4$ n'a aucune solution réelle !
Seule $X_1 = 1$ convient $\implies x^2 = 1 \implies x = \pm 1$.
D'où $S_b = \{-1\,;\, 1\}$.

c) $2x^4 + 5x^2 + 3 = 0$ :
Posons $X = x^2$ ($X \ge 0$). L'équation devient $2X^2 + 5X + 3 = 0$.
$a - b + c = 2 - 5 + 3 = 0 \implies X_1 = -1$ et $X_2 = -\frac{3}{2}$.
Les deux valeurs $X_1$ et $X_2$ sont strictement négatives ! Aucune racine réelle pour $x$.
D'où $S_c = \emptyset$.

Exercice 4 : Factorisation et Étude de Signe Moyen

Soit le trinôme $P(x) = -2x^2 + 5x + 3$.
1. Calculer le discriminant $\Delta$ et déterminer les racines de $P(x)$.
2. En déduire la factorisation de $P(x)$.
3. Dresser le tableau de signe de $P(x)$.

1. Discriminant et Racines :
$a = -2, b = 5, c = 3$.
$\Delta = 5^2 - 4(-2)(3) = 25 + 24 = 49 = 7^2 > 0$.
$$x_1 = \frac{-5 - 7}{2(-2)} = \frac{-12}{-4} = 3 \quad ; \quad x_2 = \frac{-5 + 7}{-4} = \frac{2}{-4} = -\frac{1}{2}$$

2. Factorisation :
$P(x) = a(x - x_1)(x - x_2) = -2(x - 3)\left(x + \frac{1}{2}\right) = (3 - x)(2x + 1)$.

3. Tableau de Signe :
Le coefficient $a = -2 < 0$. Le trinôme est du signe de $a$ (négatif) à l'extérieur des racines, et du signe contraire à $a$ (positif) entre les racines.
• $P(x) > 0$ pour $x \in \left]-\frac{1}{2}\,;\, 3\right[$
• $P(x) < 0$ pour $x \in \left]-\infty\,;\, -\frac{1}{2}\right[ \cup \left]3\,;\, +\infty\right[$
• $P(x) = 0$ pour $x \in \left\{-\frac{1}{2}\,;\, 3\right\}$

Exercice 5 : Inéquation Rationnelle avec Piège Difficile

Résoudre dans $\mathbb{R}$ l'inéquation : $$\frac{x^2 - 3x + 2}{x - 4} \le 0$$

Étape 1 : Condition d'existence (Domaine d'étude)
Le dénominateur ne doit pas s'annuler : $x - 4 \neq 0 \iff x \neq 4$. $D_E = \mathbb{R} \setminus \{4\}$.

Étape 2 : Étude du numérateur $N(x) = x^2 - 3x + 2$
$a+b+c = 1 - 3 + 2 = 0 \implies x_1 = 1$ et $x_2 = 2$.
Le coefficient $a = 1 > 0$, donc $N(x) \le 0$ entre 1 et 2.

Étape 3 : Tableau de signe joint
Placons les valeurs charnières : $-\infty$, $1$, $2$, $4$, $+\infty$.
• $x^2-3x+2$ : $+$ sur $]-\infty, 1]$, $-$ sur $[1, 2]$, $+$ sur $[2, +\infty[$
• $x - 4$ : $-$ sur $]-\infty, 4[$, $+$ sur $]4, +\infty[$
• Quotient : $-$ sur $]-\infty, 1]$, $+$ sur $[1, 2]$, $-$ sur $[2, 4[$, $+$ sur $]4, +\infty[$.
Note : En $x = 4$, le quotient n'est pas défini (double barre).

Conclusion : On veut le quotient $\le 0$ : $$S = ]-\infty\,;\, 1] \cup [2\,;\, 4[$$

Exercice 6 : Problème Concret de Modélisation Application

Un terrain rectangulaire a un périmètre de $50$ mètres et une aire de $144$ mètres carrés. Quelles sont les dimensions (longueur $L$ et largeur $l$) de ce terrain ?

Mise en équation :
Soient $L$ et $l$ les dimensions du terrain ($L \ge l > 0$).
• Le demi-périmètre est $S = L + l = \frac{50}{2} = 25$.
• L'aire est $P = L \times l = 144$.

Propriété : Deux nombres dont la somme est $S$ et le produit est $P$ sont les solutions de l'équation du second degré : $$X^2 - S X + P = 0 \iff X^2 - 25X + 144 = 0$$

Résolution :
$\Delta = (-25)^2 - 4(1)(144) = 625 - 576 = 49 = 7^2$.
$$X_1 = \frac{25 - 7}{2} = \frac{18}{2} = 9 \quad ; \quad X_2 = \frac{25 + 7}{2} = \frac{32}{2} = 16$$

Conclusion :
La longueur du terrain est $L = 16\text{ m}$ et sa largeur est $l = 9\text{ m}$.
